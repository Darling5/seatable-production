生产交付协同 · 使用指南

生产项目管理驾驶舱

一个把 SeaTable 业务数据 + PartDB 物料库存，自动汇总成「老板 / 销售 / 仓库 / 采购 / 生产经理」各自视图的网页工作台。数据每天自动更新，按角色口令查看，可一键分享。

★零基础也能用（不需要任何账号）

你没 SeaTable、没 PartDB、不懂生产表格？照样能用。本工作台默认「本地模式」：数据存你电脑上的 CSV 文件，开箱即用，连网都不用。

最省事：用 WorkBuddy 对话
把本仓库链接 https://github.com/Darling5/seatable-production 粘贴到 WorkBuddy「我的项目 → 新建项目」，项目会自动带上技能与「生产驾驶舱」专家。然后直接对专家说：
「生成演示版驾驶舱」→ 它用内置示例数据给你一张完整网页；
「帮我建个生产计划：产品 4G 小卡，数量 100，交期 30 个工作日」→ 它自动填表，你不用懂那 14 张表。
想自己跑（会一点命令行）
git clone 本仓库 → python setup.py --local → python seed_demo.py → python cockpit.py → 打开生成的 项目管理驾驶舱.html。
✅ 本地模式 / 演示数据完全不涉及任何真实业务，可放心试玩。等你真要接自己公司的数据，再按技能说明填 SeaTable / PartDB 凭证即可（那一步才是可选的）。
🌙 夜间模式（三态）：默认跟随你系统的深色 / 浅色设置自动切换（macOS / Windows / 手机都支持）。如果自动没生效，或想单独让驾驶舱变暗而系统仍是亮色——点顶部工具栏的 「主题」按钮 即可在「自动 → 暗色 → 亮色」之间循环切换，选择会记在浏览器本地（localStorage），下次打开自动生效。

i它长什么样（一目了然）

一句话：管理者把数据接进 SeaTable / PartDB → 技能每天自动汇总 → 生成一个网页 → 用不同口令发给不同人，每人只看自己该看的。

13 步快速开始（管理者 / 项目创建人）

第 1 步 · 建项目
在 WorkBuddy 里从本仓库的 GitHub 链接一键创建「生产交付中」项目；项目会自动带上 seatable + partdb 技能和「生产驾驶舱」专家。
第 2 步 · 接数据
按技能说明把 SeaTable 云表、PartDB 库存的访问凭证填进配置（数据存在你自己的环境里，不会进公开仓库）。
第 3 步 · 生成 & 分享
对专家说「生成最新的生产项目管理驾驶舱」，它会产出网页并部署到云端；拿到链接后，用下面的口令分别发给对应的人。
✅ 之后无需每天手动操作——系统每天 9:00 自动用最新数据重建并部署，打开链接永远是最新的。

＋用大白话让 AI 帮你建生产项目（连表都不用懂）

生产数据涉及十几张表，但你完全不用管。你只管用日常说话的方式提需求，专家会通过统一入口自动写库、算日期、建关联。试试这些说法：

建生产计划
「帮我建个生产计划：产品 4G 小卡，数量 100，交期 30 个工作日」
记一笔发货
「给项目 A 发一批货，类型销售，内容见下表…」
记一笔采购
「IC 采购：物料 XX，供应商华之安，关联生产计划 #12」
问进度
「项目 B 现在到哪一步了？有没有逾期的？」

写之前 AI 会把完整内容念给你确认，你点头它才落库——不会稀里糊涂改了你的数据。

💡 在网页里建数据（一键发起，仍需确认）：驾驶舱网页按角色自带不同的「新建」向导，写入口只开放给该角色——老板 / 仓库 / 采购页没有新建、也没有补录**（补录缺失数据、新建均为项目经理职责）。具体分流：
· 销售：看到「🆕 新建项目」向导，提交后写入 SeaTable「项目」表（即销售立项表单）；
· 生产经理：看到「🆕 新建生产计划」向导，提交后写入「生产计划」表。
填产品/数量/交期，点「🚀 一键发起 → WorkBuddy 预填待确认」——它会把信息整理成文字、复制到剪贴板，并用真实深链 workbuddy://task?action=start&prompt=…&skills=seatable-production 拉起本地 WorkBuddy、自动预填任务并开始执行。注意：按技能铁律「任何增删改必须先向你确认」，专家会先列出完整数据等你点头，你确认后才会写库、算缺料、刷新驾驶舱——所以不是全自动落库，但仍省去了手动复制粘贴（和百度云/夸克在网页点下载、自动拉起本地客户端同理）。
· 「一键发起」通常安装/首次启动即自动注册 workbuddy:// 协议，无需手动设置；仅当点击没反应时，才去 WorkBuddy 桌面端 Claw设置 → 协议注册 开启一次（开关为一次性，开过即永久生效）。
· 没装桌面端 / 没启用协议：点表单里的「🌐 网页版提交（workbuddy.cn）」按钮，在浏览器打开 https://www.workbuddy.cn/ 粘贴发送同样可以（网页版需先登录）。
· 也给想用命令行的人保留了「下载 JSON（备用）」按钮。

2角色与口令（谁能看什么）

打开链接后需要输入口令。口令分两类：

管理员

生产经理 / 项目经理 / 你自己
用管理员口令进入，可看全部 5 个角色视图、自由切换，并在页面上管理 / 轮换口令。
角色用户

老板 / 销售 / 仓库 / 采购
用各自口令进入，只能看自己那一份视图，且无法切换到别人（改网址也进不去）。敏感财务仅老板可见。

口令示例（实际以管理员页面显示为准）

身份口令示例可见范围
管理员 全览ADMIN-XXXX全部 5 视图 + 口令管理
老板BOSS-XXXX全局指标 / 成本 / 应收 / 行动建议（仅看数据，无新建 / 补录写入口）
销售SALE-XXXX项目进度 / 交期 / 应收 + 新建项目（销售立项，写「项目」表）
仓库WH-XXXX物料库存预警 / 缺料 / 齐套率
采购PU-XXXX采购逾期 / 供应商准时率
生产经理PM-XXXX在制品 / 产线流转 / 工时
⚠️ 口令写在网页里（已做编码混淆，非明文），属于「防随手误看」级别，不是银行级加密。口令万一泄露，管理员在页面点「轮换全部口令」立即生成新口令，并重新部署即可让旧口令作废。

?常见问题

数据存在哪里？安全吗？

业务数据存在你自己的 SeaTable / PartDB 环境，截图和汇总网页也只部署在你自己的云端实例。本 GitHub 仓库只放「生成器代码」，不放任何真实业务数据，可安全公开。

别人改网址里的 #role 能看别人的数据吗？

不能。每个角色视图绑定独立口令，且进入后视图被锁定在当前角色——非管理员手动改 #role 会被弹回原角色。

每天 9 点自动更新需要我做什么？

无需操作。系统自动拉取最新数据 → 重新生成网页 → 重新部署。你每天打开链接就是最新状态。

口令忘了 / 泄露了怎么办？

用管理员口令进入 → 页面右上「口令管理」→「轮换全部口令」立即生成新口令并复制；然后重新部署，旧口令即刻作废。

想改驾驶舱内容（加模块 / 调口径）？

在 WorkBuddy 里对「生产驾驶舱」专家提需求即可，它内置了生成脚本，改完重新生成部署。

我没有 SeaTable / PartDB，能用吗？

能。默认就是「本地 CSV」模式，零配置、不需要任何账号，用内置演示数据就能看完整效果（见顶部「★ 零基础也能用」一节）。等你真要接自己公司的云端数据，再填凭证切换即可。

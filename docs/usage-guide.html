生产经理第二大脑 · 使用指南

从生产协同到正式采购单，一套公共模板跑通

管理生产计划、分角色驾驶舱，也把采购合同自动转成标准 BOM 扩量、库存审核和供应商采购订单。业务台账可用本地 CSV 或 SeaTable；库存可选 PartDB、现有 ERP 的 API/MCP，或 Excel/CSV 离线文件。

i一眼看懂：你只需要选一条路

这个工具不是一张复杂的“技术架构图”，而是帮生产经理完成三件事：管生产、把合同变成采购单，以及把微信群消息变成可核对的业务情报。

我要管生产

适合日常进度、交期、库存、成本和角色协同。

1说一句人话例如“建 100 台生产计划，30 个工作日交货”。
2AI 整理并确认自动算日期、补默认值；写入前先把完整内容给你看。
3写入生产台账数据保存到本地 CSV 或你自己的 SeaTable。
4得到分角色驾驶舱老板、销售、仓库、采购和生产经理各看所需信息。

我要从合同做采购单

适合拿到客户合同后，快速算出缺料并形成正式供应商订单。

1上传合同识别产品和数量，自动匹配客户本地标准 BOM。
2核对库存可接 PartDB、ERP API、MCP 或 Excel/CSV 文件。
3人工审核缺料确认可用库存、采购数量、供应商和单价，不自动下单。
4生成正式采购单按供应商分组输出 PDF；关键信息不完整就停止。
共同底线：任何写入都先给人确认；客户公司信息、BOM、库存和 ERP 凭证只放在本地，不进入公共仓库。
第三条路 · 消息核对：微信保持 PC 版登录，跑一次 python wxmatch.py scan，群里的收款、新下单、合同 PDF 就会与业务表逐条对账——专抓「群里说了但表里没有」的缺口。核对引擎只读，高置信项只生成预填意图，你确认后才写库。

采合同到正式采购单

这是与生产驾驶舱并列的核心能力。合同进入后不会直接下单，而是经过可检查、可人工修改的工件链路：

1. 合同与 BOM
识别产品数量，自动绑定客户本地标准 BOM；数量行缺少料号或型号时硬阻断，避免静默漏料。
2. 多库存源核对
支持 PartDB、REST API、MCP 与 Excel/CSV。API/MCP 可配置登录、Token、分页和嵌套字段映射。
3. 人工库存审核
普通库存默认属于未确认库存，不会直接抵扣生产缺口；审核人员确认采购数量、供应商和单价。
4. 正式采购订单
按供应商分组生成 PDF。公司抬头、地址、付款条款或单价不完整时禁止生成正式订单。
首次配置
python pipeline/run.py init → 填写 pipeline/rules.local.yaml 和本地 config.yaml → python pipeline/run.py preflight。
执行链路
prepare → audit → 人工审核 → plan → pdf。若同步 SeaTable，submit 还需要显式 --yes。

核消息↔SeaTable 核对（v1.6.2）

微信情报解决「群里说了什么」，核对引擎解决更难的一件事：群里说的和表里记的对不对得上。它专抓「群里说了但表里没有」的缺口——比如群里发了盖章合同 PDF，项目表的合同列却还是空的。

四类对账

类型群里看到的对哪张表匹配规则
收款「已打款 xx 万」「到账了」项目表「待收」金额 ±2% 容差 → 高置信

原原料行情（金 / 银 / 铜 / 锡 + 塑料原料）

元器件之外，还有一层更上游的成本在悄悄影响毛利：锡价直接决定 SMT 焊料成本，铜价决定 PCB 与线材，金银决定镀层与键合线，ABS / PC / PS 决定外壳与结构件。这一层单独监控，成本异动时你比供应商先知道。

三个层级：全自动 / 代理指标 / 人工录入

品种类别数据源单位怎么更新
黄金 / 白银 / 铜 / 锡 / 铝 / 镍金属新浪期货连续合约元/克、元/千克、元/吨全自动，跑一次全部取回
聚丙烯 PP / 聚乙烯 LLDPE / PVC塑料代理指标新浪期货连续合约元/吨全自动
ABS / PC / PS 树脂塑料现货—元/吨人工录入（填你的采购报价）
关于塑料，说句实话：ABS、PC、PS 是石化下游现货品种，没有公开的免费 API —— 报价被生意社、卓创、中塑在线等资讯商垄断（付费）。 所以本模块的做法是：金属全自动；PP / LLDPE / PVC 期货作为其上游石化链的代理指标（趋势相关，能提前感知塑料成本拐点）； ABS / PC / PS 现货走人工录入，把你的实际采购价填进去即可积累走势。 日后若接入含产业数据的付费源（如同花顺 iFinD 有化工品现货库），只需加一个 source 适配器，数据结构与展示都不用动。

数据源要不要申请 API key？

不需要。金属与塑料代理指标走新浪财经的期货公开接口（上期所 / 大商所连续合约），免费、无需注册、无配额风险，人民币计价。历史补录走东方财富 K 线（新浪的日 K 线服务已下线）。整个模块不保存任何 API key。

为什么同一原料会有两行（连续·实时 / xxxx·历史）？

因为口径不同：每日自动抓取的是「连续合约」当日价；补录的历史是「具体合约」（如 au2612）的 K 线。两者数值天然有差异，环比只在同口径内计算 —— 拼接不同口径会凭空造出假涨跌。这也是为什么「连续·实时」刚建库时区间涨跌显示「—」：它还没有同口径的历史点，每天跑一次就有了。

同花顺 / iFinD 这类付费源值得接吗？

看你要什么：期货部分不用——免费源已覆盖金 / 银 / 铜 / 锡 / 铝 / 镍 / PP / LLDPE / PVC；ABS / PC / PS 现货才是真缺口，这块 iFinD 有化工品现货库但要付费，MindGo 等量化平台只有行情、没有现货报价。若确认要接，在 commodities.py 里加一个 source 适配器即可，CSV 结构与展示层不用改。

4拿到链接后，发给别人

推荐用 WorkBuddy 团队资料库分发：publish.py 把驾驶舱发布为固定链接（形如 https://www.workbuddy.cn/space/d/xxxx），每天自动覆盖更新、链接不变，谁能看由空间协作者权限决定（owner / editor / reader，服务端控制，页内口令只负责分拣角色视图）。

?常见问题

数据存在哪里？安全吗？

业务台账保存在你自己的本地 CSV 或 SeaTable；库存可来自 PartDB、客户 ERP API/MCP 或导出文件。公开仓库只放通用代码、规则模板和示例配置，不放公司抬头、BOM、库存、流程文件、ERP 地址或凭证。

别人改网址里的 #role 能看别人的数据吗？

不能。每个角色视图绑定独立口令，且进入后视图被锁定在当前角色——非管理员手动改 #role 会被弹回原角色。

每天 9 点自动更新需要我做什么？

无需操作。系统自动拉取最新数据 → 重新生成网页 → 覆盖发布到团队资料库（链接不变）。你每天打开链接就是最新状态；微信情报同步要求本机微信 PC 版保持登录。

微信情报会自动改我的业务数据吗？

不会。群消息提取出的交期 / 价格 / 催货等事件一律进入「待确认」清单，你在对话里确认后才会写入业务表，原文和写入结果全程留痕。整个链路只读本地微信数据库，不连接微信服务器。

消息核对引擎会自动改我的业务数据吗？

同样不会，而且更严格：核对引擎本身只读——它把群消息与 SeaTable 业务表逐条比对（收款 / 下单 / 合同 PDF / 供应商合同），只生成「待核对清单」和「预填意图」，任何写库动作都要你在对话里确认后才执行（复用微信情报的 approve 链路）。

口令忘了 / 泄露了怎么办？

用管理员口令进入 → 页面右上「口令管理」→「轮换全部口令」立即生成新口令并复制；然后重新部署，旧口令即刻作废。

已有金蝶、简道云、禅道或自建 ERP，必须先导出 Excel 吗？

不必须。优先使用 api 或 mcp 在线读取库存；配置接口地址、鉴权、分页、响应路径和字段映射即可。只有 ERP 没有可用接口或现场网络受限时，才使用 Excel/CSV 文件源。

API/MCP 读到的库存会自动承诺生产吗？

不会。API、MCP 和文件源中的通用库存默认列为未确认库存，必须经过人工审核后才可用于生产承诺。

我没有 SeaTable / PartDB，能用吗？

能。业务台账默认使用本地 CSV；采购库存可以先使用 Excel/CSV 文件源。已有 ERP 时优先接 API/MCP，没有 ERP 时再考虑部署 PartDB。

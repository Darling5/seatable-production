生产经理第二大脑 · 使用指南

从生产协同到正式采购单，一套公共模板跑通

管理生产计划、分角色驾驶舱，也把采购合同自动转成标准 BOM 扩量、库存审核和供应商采购订单。业务台账可用本地 CSV 或 SeaTable；库存可选 PartDB、现有 ERP 的 API/MCP，或 Excel/CSV 离线文件。

★零基础也能用（不需要任何账号）

没有 SeaTable、PartDB 或现成 ERP？照样能用。业务台账默认使用本地 CSV；采购库存可从 Excel/CSV 起步，之后再切换 PartDB、ERP API 或 MCP，采购审核逻辑无需重写。

i一眼看懂：你只需要选一条路

这个工具不是一张复杂的“技术架构图”，而是帮生产经理完成两件事：管生产，以及把合同变成采购单。

我要管生产

适合日常进度、交期、库存、成本和角色协同。

1说一句人话例如“建 100 台生产计划，30 个工作日交货”。
2AI 整理并确认自动算日期、补默认值；写入前先把完整内容给你看。
3写入生产台账数据保存到本地 CSV 或你自己的 SeaTable。
4得到分角色驾驶舱老板、销售、仓库、采购和生产经理各看所需信息。

我要从合同做采购单

适合拿到客户合同后，快速算出缺料并形成正式供应商订单。

1上传合同识别产品和数量，自动匹配客户本地标准 BOM。
2核对库存可接 PartDB、ERP API、MCP 或 Excel/CSV 文件。
3人工审核缺料确认可用库存、采购数量、供应商和单价，不自动下单。
4生成正式采购单按供应商分组输出 PDF；关键信息不完整就停止。
共同底线：任何写入都先给人确认；客户公司信息、BOM、库存和 ERP 凭证只放在本地，不进入公共仓库。

13 步快速开始（管理者 / 项目创建人）

第 1 步 · 建项目
在 WorkBuddy 里从本仓库的 GitHub 链接创建项目；项目会带上 seatable-production 技能和「生产驾驶舱」专家。
第 2 步 · 接数据
业务台账选择本地 CSV 或 SeaTable；采购库存选择 PartDB、ERP API、MCP 或 Excel/CSV。全部客户字段和凭证只填本地配置，不进入公开仓库。
第 3 步 · 生成与采购
可以生成生产驾驶舱并分享；也可以只上传采购合同，自动匹配标准 BOM、生成库存审核表，人工批准后输出按供应商分组的正式采购订单 PDF。
可选 · 开微信情报
微信 4.x 保持 PC 版登录即可（pip install cryptography），AI 自动从本地加密库拉监控群消息；用 python wechat_intake.py doctor 体检、groups 挑监控群。
✅ 驾驶舱可按需设置自动更新；采购链路始终保留人工库存审核，SeaTable 写入也必须显式确认。

＋用大白话让 AI 帮你建生产项目（连表都不用懂）

生产数据涉及十几张表，但你完全不用管。你只管用日常说话的方式提需求，专家会通过统一入口自动写库、算日期、建关联。试试这些说法：

建生产计划
「帮我建个生产计划：产品 4G 小卡，数量 100，交期 30 个工作日」
记一笔发货
「给项目 A 发一批货，类型销售，内容见下表…」
记一笔采购
「记录一笔 IC 采购，关联生产计划 #12」
合同出采购单
「用这份合同自动匹配 BOM，生成库存审核表」
问进度
「项目 B 现在到哪一步了？有没有逾期的？」

写之前 AI 会把完整内容念给你确认，你点头它才落库——不会稀里糊涂改了你的数据。

💡 在网页里建数据（一键发起，仍需确认）：驾驶舱网页按角色自带不同的「新建」向导，写入口只开放给该角色——老板 / 仓库 / 采购页没有新建、也没有补录**（补录缺失数据、新建均为项目经理职责）。具体分流：
· 销售：看到「🆕 新建项目」向导，提交后写入 SeaTable「项目」表（即销售立项表单）；
· 生产经理：看到「🆕 新建生产计划」向导，提交后写入「生产计划」表。
填产品/数量/交期，点「🚀 一键发起 → WorkBuddy 预填待确认」——它会把信息整理成文字、复制到剪贴板，并用真实深链 workbuddy://task?action=start&prompt=…&skills=seatable-production 拉起本地 WorkBuddy、自动预填任务并开始执行。注意：按技能铁律「任何增删改必须先向你确认」，专家会先列出完整数据等你点头，你确认后才会写库、算缺料、刷新驾驶舱——所以不是全自动落库，但仍省去了手动复制粘贴（和百度云/夸克在网页点下载、自动拉起本地客户端同理）。
· 「一键发起」通常安装/首次启动即自动注册 workbuddy:// 协议，无需手动设置；仅当点击没反应时，才去 WorkBuddy 桌面端 Claw设置 → 协议注册 开启一次（开关为一次性，开过即永久生效）。
· 没装桌面端 / 没启用协议：点表单里的「🌐 网页版提交（workbuddy.cn）」按钮，在浏览器打开 https://www.workbuddy.cn/ 粘贴发送同样可以（网页版需先登录）。
· 也给想用命令行的人保留了「下载 JSON（备用）」按钮。

采合同到正式采购单

这是与生产驾驶舱并列的核心能力。合同进入后不会直接下单，而是经过可检查、可人工修改的工件链路：

1. 合同与 BOM
识别产品数量，自动绑定客户本地标准 BOM；数量行缺少料号或型号时硬阻断，避免静默漏料。
2. 多库存源核对
支持 PartDB、REST API、MCP 与 Excel/CSV。API/MCP 可配置登录、Token、分页和嵌套字段映射。
3. 人工库存审核
普通库存默认属于未确认库存，不会直接抵扣生产缺口；审核人员确认采购数量、供应商和单价。
4. 正式采购订单
按供应商分组生成 PDF。公司抬头、地址、付款条款或单价不完整时禁止生成正式订单。
首次配置
python pipeline/run.py init → 填写 pipeline/rules.local.yaml 和本地 config.yaml → python pipeline/run.py preflight。
执行链路
prepare → audit → 人工审核 → plan → pdf。若同步 SeaTable，submit 还需要显式 --yes。

?常见问题

数据存在哪里？安全吗？

业务台账保存在你自己的本地 CSV 或 SeaTable；库存可来自 PartDB、客户 ERP API/MCP 或导出文件。公开仓库只放通用代码、规则模板和示例配置，不放公司抬头、BOM、库存、流程文件、ERP 地址或凭证。

别人改网址里的 #role 能看别人的数据吗？

不能。每个角色视图绑定独立口令，且进入后视图被锁定在当前角色——非管理员手动改 #role 会被弹回原角色。

每天 9 点自动更新需要我做什么？

无需操作。系统自动拉取最新数据 → 重新生成网页 → 覆盖发布到团队资料库（链接不变）。你每天打开链接就是最新状态；微信情报同步要求本机微信 PC 版保持登录。

微信情报会自动改我的业务数据吗？

不会。群消息提取出的交期 / 价格 / 催货等事件一律进入「待确认」清单，你在对话里确认后才会写入业务表，原文和写入结果全程留痕。整个链路只读本地微信数据库，不连接微信服务器。

口令忘了 / 泄露了怎么办？

用管理员口令进入 → 页面右上「口令管理」→「轮换全部口令」立即生成新口令并复制；然后重新部署，旧口令即刻作废。

已有金蝶、简道云、禅道或自建 ERP，必须先导出 Excel 吗？

不必须。优先使用 api 或 mcp 在线读取库存；配置接口地址、鉴权、分页、响应路径和字段映射即可。只有 ERP 没有可用接口或现场网络受限时，才使用 Excel/CSV 文件源。

API/MCP 读到的库存会自动承诺生产吗？

不会。API、MCP 和文件源中的通用库存默认列为未确认库存，必须经过人工审核后才可用于生产承诺。

我没有 SeaTable / PartDB，能用吗？

能。业务台账默认使用本地 CSV；采购库存可以先使用 Excel/CSV 文件源。已有 ERP 时优先接 API/MCP，没有 ERP 时再考虑部署 PartDB。

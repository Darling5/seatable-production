# 业务流程速查（8 阶段）

本文件是 SKILL.md 的扩充参考，覆盖从立项到售后的完整周期。所有数据读写仍走 `op.py`，与后端无关。

## 阶段一：项目立项
- 整理：项目名称、产品需求(Markdown 表格)、合同总价、签订日期、合同交期、付款条款(下单付/收货付/验收付)、实收金额。
- 区分：已签合同 / 待签合同 / 口头订单 / 框架协议。
- 输出：立项清单、产品需求明细、应收款提醒。
- ⚠️ 产品需求必须用 Markdown 表格（列头：产品名称/型号/数量/单价/金额），不能纯文本。

## 阶段二：生产计划制定
- 拆解：生产产品、数量、工序(默认含 09测试、10出货)、关联项目、合同交期。
- 自动：立项日期=今天；交货日期=立项+交期工作日。
- 输出：生产计划单、工序清单、交期倒计时。
- ⚠️ 必须关联项目(列近1个月供选)；工序可多选；13(09测试)/14(10出货)默认自动加。

## 阶段三：采购管理
- 流程：整理物料→供应商→数量/价格/交期(天)/下单时间/到货时间；识别缺料/逾期/价格异常/比价。
- 输出：采购订单、交期跟踪表、逾期预警。
- 标准流程：用户发采购截图(华秋/嘉立创)→AI 提取字段→确认后写入。
- ⚠️ 数值字段(数量/价格/交期)没提到就后补，每周五 14:00 统一提醒。
- 各表特殊规则见 SKILL.md §6。

## 阶段四：生产执行跟踪
- 跟踪：贴片→组装→测试→包装→入库 的进度、良品率、阻塞、交期风险。
- 输出：生产周报、质量异常报告、交期预警。
- ⚠️ 贴片/组装良品数据可更新到对应记录，良品率公式自动算。

## 阶段五：库存核对
- 核对：IC/PCB板/组装物料/PCBA贴片成品/自生产成品 的数量与位置。
- 输出：库存核对记录、缺料采购建议、盘点报告。
- ⚠️ 可关联对应生产计划，核对结果自动归档。

## 阶段六：发货交付
- 整理：产品名称/固件版本/产品型号/数量/ID号/SIM卡号(**Markdown 表格**)；区分销售/借测/送样/维修出库。
- 输出：发货清单、快递单号、客户签收。
- ⚠️ 借测必填返还日期；维修必关联维修记录。格式规则见 SKILL.md §7。

## 阶段七：维修售后
- 整理：维修清单、问题描述、返修时间、要求交期(天)、关联项目(列全部项目，不限近1个月)。
- 输出：维修记录、质量分析、供应商追责建议。
- ⚠️ 完成时间/处理方法后补。

## 阶段八：数据分析与看板
- 五大类：工时 / 成本 / 质量 / 供应链 / 综合看板(四维一体)。
- 输出：文字摘要(企微)、表格(对比)、图表(可视化)、详细报告(腾讯文档)。
- ⚠️ 可设定时看板（每周五 18:00 自动生成发送企微）。

## 四类流程节点速查

### 采购流程
```
采购触发 → 研发确认(BOM/PCB布局)
  PCB采购 → 打样(华秋) / 批量(供应商)
  BOM采购 → 整理BOM → 核对库存 → 缺料询价/比价 → 下单 → 物流 → 到货核对 → 入库
  组装料采购 → 与组装厂沟通库存 → 缺料联系 → 下单 → 到货抽检 → 定制料测试留档
  贴片 → PCBA物料给料 → 核对损耗 → 登记入库
  外壳采购 → 下单 → 到货登记
  产品外购 → 批次要求 → 联系供应商 → 记录/跟进/专票
```

### 生产流程
```
触发：物料到齐 / 市场合同签订
  贴片厂：首贴打样 → 测试 → 小批量打样 → 投产计划书
  批量生产：抽样 → PCBA品测 → 治具配套
  组装厂：包装盒监测 → 外壳组装监测 → PCB板组装监测 → 灌胶/标签
  生产总结：单次生产报告 → 生产总结会
```

### 生产库存管理
```
触发：物料采购 / 成品采购 / 贴片成品 / 产品发货 / 每月盘点
  入库：IC物料 / PCB板 / 组装物料 / PCBA贴片成品 / 自生产成品 / 成品采购 / 返修
  出库：贴片物料 / 组装物料 / 采购成品 / 自生产产品
  盘点：库存数量 / 存放位置 / 封装规格
```

### 行政仓库
```
仓库：入库/出库/盘点（同生产库存管理）
行政：办公备料 / 公司福利 / 日常打扫 / 接待 / 杂项(物业/网络/设备/出行/报销)
```

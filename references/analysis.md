# 分析功能明细（四维一体）

触发词：分析 / 统计 / 报表 / 看板。数据全部来自 `op.py list/query`（本地或 SeaTable 皆可）。

## 项目生命周期甘特图

读取 `项目阶段`，按计划开始/完成绘制立项、样机、打样、开模、试产、认证、量产和结项；用实际时间覆盖已发生节点。按 `前置阶段` 计算依赖，并标记：

- 计划完成已过但状态未完成；
- 阻塞或评审不通过；
- 下一步截止日临近；
- 项目阶段与生产批次未关联；
- EVT/DVT/PVT 放行状态不明确。

项目甘特图展示跨阶段进展；生产甘特图继续展示库存、采购、贴片、组装、测试和出货执行。

## 一、工时分析（交付能力）
1. **交期达成率** = 准时完成数 / 总生产计划数。准时定义：完货日期 ≤ 合同交期。按项目分组，标红逾期。
2. **生产周期** = 成品完成时间 − 立项日期；对比合同交期天数，列过长/过短项目。
3. **工序耗时** = 基于生产工序表统计每道工序平均耗时，识别瓶颈工序。
4. **在制品看板** = 筛选状态≠已完成，显示产品/数量/阶段/立项/剩余时间，按剩余时间升序。

## 二、成本分析（盈利能力）
1. **项目利润** = 合同总价 − 生产总花销；利润率 = 利润/合同总价。标红亏损/低利润。
2. **成本结构** = 汇总生产总花销，按 PCB/外壳/IC/贴片/PCBA/组装料/组装价格/成品采购 分组，饼图/柱状图。
3. **预算 vs 实际** = 预算(合同总价×目标利润率反推) vs 实际(生产总花销)，超预算预警。
4. **应收款** = 筛选实收<合同总价，按合同交期升序催收。
5. **现金流预测** = 采购花销(未来支出)+合同收款(未来收入)，输出 30/60/90 天。

## 三、质量分析（交付质量）
1. **维修率** = 维修记录数 / 发货数量 ×100%，按项目/产品分组。
2. **良品率** = 良品数量 / 贴片(或组装)数量 ×100%，按贴片厂/组装厂分组。
3. **返修时效** = 返修时间→完成时间 平均时长，列超期未完修。
4. **质量成本** = 维修额外成本(返工人工/物料损耗)占营业额比例。

## 四、供应链分析（交付保障）
1. **采购逾期** = 到货时间>今天且状态≠已到货/已入库；或 下单+交期<今天 且到货仍空。
2. **供应商交期准确率** = 准时到货数 / 总订单数；准时=到货≤下单+交期。按供应商排行。
3. **供应商价格对比** = 同类型物料不同供应商报价对比，列偏高者。
4. **库存预警** = 库存核对记录中最终完成时间为空或结果异常，列待核对/异常。

## 五、综合看板（一键生成）
```
📊 生产管理看板（2026-06-01 ~ 2026-06-07）
【工时】交期达成率 85%(17/20) | 逾期 3 | 在制品 5，最快逾期：项目D(剩2天)
【成本】总合同 XXX | 总花销 XXX | 利润 XXX，利润率 XX% | 超预算 2 | 应收款 XXX(逾期 XXX)
【质量】维修率 X% | 贴片良品率 XX% | 组装良品率 XX% | 超期未完修 X
【供应链】采购逾期 X | 交期准确率 平均 XX% | 库存待核对 X
```

## 输出格式
- 文字摘要：适合企微快速查看。
- 表格：适合对比分析。
- 图表：可视化（canvas/图表工具）。
- 详细报告：导出腾讯文档。
